PROYECTO-RETO: PROGRAMACIÓN y ENTORNOS DE DESARROLLO - 1º DAM
1. Descripción del proyecto o reto
El presente reto consiste en el análisis, modelado e implementación de un sistema software
para la gestión de distintas áreas de un hospital.
El hospital ficticio Nuevo Obispo Polanco de Teruel necesita desarrollar un sistema informático que
permita gestionar diferentes procesos internos como:
● gestión clínica de pacientes
● hospitalización
● urgencias y triaje
● farmacia hospitalaria
● inventarios y suministros
● gestión médica y asistencial
Cada grupo de estudiantes será responsable de una de estas áreas, para la cual deberá:
1. Analizar el enunciado del problema
2. Modelar el sistema mediante UML
3. Diseñar la estructura de clases
4. Implementar el sistema en Java
5. Documentar el proceso
