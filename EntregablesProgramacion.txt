Entregables para Programación
IMPLEMENTACIÓN DEL PROGRAMA EN JAVA
- El programa tendrá que ser funcional. Es decir, deberá funcionar correctamente y realizar
las acciones necesarias para cumplir con los requisitos. Dependiendo de cada proyecto,
podrían ser, por ejemplo:
● Registro de pacientes, material, médicos, inventario, personal, diagnósticos...
● Recopilación de antecedentes médicos (enfermedades, alergias, medicación, etc.),
historiales médicos, pedidos...
● Consultas necesarias para cumplir con los requisitos.
● Posibilidad de modificar los datos que puedan ser susceptibles de ser modificados.
● Actualizaciones de stock, bajas de pacientes, etc.
● Notificación al área de facturación (simulada, por ejemplo, con un mensaje por
consola).

- El programa deberá permitir navegar hacia las diferentes opciones a través de menús y
submenús
● Interfaz de consola con menús claros y navegación entre opciones.
● Submenús para pacientes, médicos, historial, consultas, etc.
● Validación de entradas del usuario (evitar errores por datos mal ingresados).
● Búsqueda de pacientes, productos, disponibilidad de camas, ...

- Diseño orientado a objetos
● Uso de clases independientes.
● Herencia, clases abstractas (si las hubiera) e interfaces (si las hubiera).

● Atributos privados con los getters y setters necesarios.
● Métodos bien definidos para las acciones clave del sistema.

PROYECTO-RETO: PROGRAMACIÓN y ENTORNOS DE DESARROLLO - 1o DAM

● Separación de responsabilidades entre clases.
● Uso de estructuras como listas, mapas y/conjuntos para almacenar datos.

- Persistencia de datos

● Almacenamiento de la información en ficheros de texto y de objetos.
● Carga automática desde un fichero de algunos de los datos (por ejemplo, datos de
pacientes/médicos, etc. que estén guardados en un fichero de texto) al iniciar el
programa.
● Opción de guardar los cambios cuando se modifica la información.

- Calidad del código
● Código bien estructurado, indentado y con comentarios explicativos.
● Nombres descriptivos para clases, métodos y variables.
● Manejo de errores con excepciones y validaciones de entrada.
● Evitar duplicación de código (uso de funciones reutilizables).
●
● El programa no deberá abortar bajo ningún concepto.
